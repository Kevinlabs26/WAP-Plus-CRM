# WAP Plus CRM — 产品需求（现行）

> **多号 WhatsApp 销售工作台 + 本地 CRM**  
> 主品牌：**WAP Plus CRM** · 工程 id 仍为 `wap-plus-crm`

本文描述**当前产品真实形态**。早期「电脑投屏控制安卓 WhatsApp Business」方案已降级为**真机 Bridge 备用通道**，不再作为默认 UX。

---

## 一、产品定位

### 目标用户
外贸、跨境电商、销售、客服、自由职业、中小团队负责人（单人/小团队运营多号）。

### 一句话
在电脑上用**自建聊天气泡工作台**连接 WhatsApp（默认 Baileys 扫码），统一会话、客户阶段、跟进、星标与 AI 辅助；数据默认落在本机。

### 核心差异化
| 是 | 不是 |
|----|------|
| 销售 CRM + 多号工作台 | 官方 WhatsApp 客户端 |
| 自建 UI（消息列表/气泡） | 中间嵌手机实时画面（旧方案） |
| 本地优先（SQLite / IDB） | 强制业务上云 |
| Baileys 主路径 + 真机备用 | Cloud API / 模板群发平台 |

### 核心流程（现行）
```
扫码连接账号槽 → 同步会话/联系人 → 侧栏选客户
  → 中间自建聊天区收发 → 右侧 CRM/AI
  → 跟进/星标/阶段自动记录 → 本机备份可导出恢复
```

## 二、整体架构

```
Windows Desktop (Tauri 2 + React + TS + Rust)
├── WAP Plus CRM UI：会话 · CRM · 跟进 · 星标 · 统计 · 设备
├── 状态：Zustand appStore + SQLite（桌面）/ IDB（浏览器预览）
│
├──【默认】Baileys Bridge（Node 子进程，每号一 session）
│     扫码 · 收发 · 历史 · 群 · 反应 · 媒体按需 …
│
└──【备用】Android Bridge（Kotlin）
      真机 WhatsApp Business 辅助发送 / 设备状态 / 悬浮卡
      能力明显少于 Baileys，不作功能对等承诺
```

## 三、功能模块（与实现对照）

### ① 账号与连接
- **Baileys**：多账号槽、顶栏切换、状态与头像、同步会话
- **Android Bridge**：Host/Port、设备在线/电量（备用）
- 发送限速、过热拦截、账号健康度

### ② 聊天工作台（Baileys 主能力）
- 文本 / 图片 / 语音 / 贴纸 / 文件 / 商品目录
- 引用、转发、编辑、删除/撤回、表情回应
- 会话内搜索、全局消息搜索（含冷历史）
- 群：建群、资料、邀请、入群申请、@
- 本地星标（不同步手机官方星标）
- 会话静音 / 置顶 / 归档（协议能力范围内）

### ③ CRM
- 联系人：姓名、电话、公司、来源、标签、阶段、备注、账号归属
- 阶段：新客户 → 已联系 → 报价中 → 成交 → 售后
- 同一自然人多号碰撞提示、主号指定
- 内部备注（客户不可见）

### ④ AI（设置可选）
- 提供商（现行实现）：OpenAI / Groq / Gemini / Ollama / mock  
  （Claude 为规划项，未默认接入）
- 能力方向：回复建议、翻译草稿、摘要与跟进提示（以设置页实际为准）

### ⑤ 跟进与统计
- 跟进列表、自动跟进规则（可关）
- 基础统计：今日活跃、待回复、待跟进、成交等
- 桌面通知：实时入站系统通知（可关；静音/前台抑制）

### ⑥ 数据
- 导出 JSON v2（多号安全设置；**不含** API Key / 扫码凭证）
- **导入恢复** CRM 数据（换机后号仍需重连）
- 导出联系人 CSV（含 accountId）

## 四、Windows 界面布局（现行）

```
--------------------------------------------------------------
顶栏：Logo · 账号切换（头像/状态） · 导航 · 搜索(⌘K) · 设置
--------------------------------------------------------------
侧栏会话/联系人 | 自建消息列表+输入 | 右侧 CRM / AI
--------------------------------------------------------------
```

- **中间不是手机投屏**，是 WAP Plus CRM 自绘气泡与媒体。
- 设备页管理账号槽与（可选）真机 Bridge，不承担主聊天 UI。

## 五、通道能力边界（诚实说明）

| 能力 | Baileys | Android Bridge |
|------|---------|----------------|
| 扫码多号桌面聊 | ✅ 主路径 | ❌ |
| 完整历史/冷历史 | ✅ | 有限 / 视桥实现 |
| 反应 / 编辑 / 群管理 | ✅ | ❌ 或不对等 |
| 真机发出、防封叙事 | 弱（勿宣传） | ✅ 主叙事 |
| 悬浮 CRM 卡 | — | ✅ 方向 |

默认推荐 **Baileys**；需要「必须从手机 App 点发送」时再切真机。
