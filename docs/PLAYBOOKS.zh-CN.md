# Playbook 资料库与绑定

## 从 Muse 自动同步

在「设置 → AI → Playbook 资料库」点击「从 Muse 读取 / 同步」。首次需要已登录 Muse；成功后关联它返回的工作区目录，并启用应用打开期间的每小时空闲检查。可以关闭自动检查，仍随时手动同步。

此入口通过现有 Muse 网页生成通道，让 Muse 使用自己的文件工具读取工作区，**不是 Muse 官方文件下载 API**。先读取 Playbook 清单、路径和文件 SHA-256；再分批读取新增或变更的文件，生成精简内容。未变化的文件沿用缓存。若工作区存在多套难以区分的资料，需在 Muse 工作区提供明确的同步清单；程序不会任意选择来源。

同步请求不包含客户聊天记录或本地 Playbook 正文，使用独立的新 Muse 对话。同步属于低优先级任务；自动检查只在界面可见、启动完成且 Muse 文字队列空闲时发起，失败后不会立即循环重试。每次检查仍会使用 Muse 生成任务，实际耗时和可读取范围取决于 Muse 的登录及文件工具状态。

本地只缓存从 Muse 得到的精简内容和来源、版本信息，完整原文保留在 Muse 工作区。首次同步后应核对资料名称和精简版；返回的路径和版本来自 Muse 的读取结果，并非本程序独立访问文件系统验证。

任一批次失败、版本不一致、恢复备份或同步期间发生本地编辑，整次结果都不会覆盖已有资料。成功清单中不再出现的文件会保留缓存并标记缺失，其绑定暂停生成，直到重新同步或选择。备份恢复不自动启用同步，需要手动重新开启。

## 本地导入和更新（备用）

打开「设置 → AI → Playbook 资料库 → 本地文件导入（备用）」，选择「导入 / 更新 Markdown」。可以一次导入多个 `.md` 文件，下拉列表取自实际文件名，名称可以编辑。本地同名导入不会覆盖 Muse 来源的资料。

- 6000 字符以内的文件默认使用正文作为精简内容。
- 更长的文件保留完整原文，但需要手动填写并保存精简版，才可生成回复。不会自动调用 AI 做摘要。
- 「共用总纲」由你选择，不按文件编号猜测。只有客户使用 Playbook 时，才会连同所选场次发送总纲的精简版。
- 原文不会自动进入生成请求。资料库可查看原文，必要时可自行取用相关段落。
- 重新导入同名文件会保留资料 ID 和已有绑定。相同正文保留已编辑的精简版；长正文发生变更时，旧精简版会清空，需重新审核填写。
- 最多 100 份资料，单份原文 20 万字符，原文和精简版合计不超过 100 万字符。

## 绑定

- 分组：分组菜单 → AI 规则 → Playbook，保存后成为该分组的默认值。空值继承同账号范围内的上级分组。
- 客户：右侧客户资料 → Playbook，选择后自动保存。客户单独选择优先于分组，或可明确选择「不使用 Playbook」。
- 客户绑定按账号和会话隔离，同一联系人在不同账号下可使用不同资料。
- 切换资料或修改精简版会使旧回复建议缓存失效，下次生成使用新内容。Muse 沿用原有的 profile 更新机制；不是调用 Muse 产品的原生 Playbook 功能。

## 保存和异常

资料库、总纲选择、分组默认和客户绑定随现有设置落盘，并纳入备份导出与恢复。

被引用的资料不能直接删除。若绑定资料缺失或精简版未填写，生成会明确报错，不会自动改用另一份资料。合并会话时迁移账号绑定；冲突时停止生成并要求重新选择。删除会话时清理对应绑定。

导入操作只读取所选文件，不会改写磁盘上的原始 Markdown。资料在 Muse 端的历史内容不会因本地停用或删除而被清除。

## 聊天方案与每日切换

在资料库底部「聊天方案」新建方案，设置名称并逐日选择 Playbook。方案以资料 ID 引用内容，可以在不同方案中复用同一份资料，天数可按流程增减，不按文件名自动猜顺序。

文件夹 AI 设置中启用「按方案每天切换」，选择方案、开始日期、时区和每日切换时间，保存后只对该文件夹明确生效。原固定 Playbook 保留，关闭计划后可恢复使用。未设置的子文件夹继承上级；客户按账号单独绑定的 Playbook 优先，包括明确停用。

开始前仅使用基础规则；之后按文件夹时区的日历日期选择当天内容。最后一天之后继续保留最后一份资料。应用未打开期间不补发消息，重新打开后直接使用当天内容。该功能只选择生成材料，不会自行开启自动回复或主动联系。

计划和开始日期随备份保存。正在使用的方案不能直接删除；方案引用的资料同样有删除保护。来源缺失、日期无效或方案不存在时停止生成并提示，不能悄悄切回无资料的聊天。每日切换会令旧建议失效，排队的旧阶段自动回复仍受发送前上下文校验。
