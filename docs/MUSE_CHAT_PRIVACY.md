# Muse 聊天数据最小化

聊天回复建议、自动回复、主动联系和聊天表格提取在发送前默认脱敏：

- 只取当前会话、当前账号的有限消息，不附联系人姓名、电话、公司、标签、备注或旧 AI 摘要等资料卡字段。
- 保留当前回复所需的文字、语音转写、引用、时间信息及生效的基础规则 / Playbook；聊天回复不上传原始语音或附件。
- 在本机匹配已知联系人姓名、账号姓名和消息发送者姓名，遮盖这些标识，以及电话号码、邮箱、共享联系人链接和名片；本机联系人目录用于匹配，不会被发送。
- 手动、自动及主动联系共用发送前检查；检查失败不发送原文。
- 新请求使用独立的脱敏线程标识，避免复用旧 Muse 线程和续接摘要。账号、客户之间的隔离继续保留。

这不是完整的匿名化保证：自由文本中尚未登记的姓名、昵称、地址或间接身份线索可能无法自动识别，必要时需人工检查。较长的号码状数字也可能被遮盖。手动图片生成及 Playbook 文件同步不属于聊天上下文通道；明确选择的参考图可能包含个人信息。

已发送到 Muse 的旧聊天和记忆不会因此被删除，需要在 Muse 中另行管理。脱敏也不等于获得 Muse 的自动化使用许可，或自动满足全部数据保护义务。
